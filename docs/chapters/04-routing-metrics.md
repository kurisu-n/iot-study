# Μετρικές Δρομολόγησης

!!! todo "Υπό συγγραφή (☆)"

    Το κεφάλαιο αυτό δεν έχει γραφτεί ακόμη. Θα καλύψει τις μετρικές δρομολόγησης και τη μετρική Expected Transmission Count (ETX): πώς μετριέται η ποιότητα μιας ζεύξης, το ενεργειακό μοντέλο της μετάδοσης, και τη λυμένη άσκηση πολυβηματικής μετάδοσης με τα ακριβή νούμερα.

    **Σειρά προτεραιότητας: 1.** Καλύπτεται από τις χειρόγραφες σημειώσεις (σελίδες 15 έως 16). **Απαντά** στο [Θέμα Δ.1 του 2026](../exams/2026.md#d1), μια άσκηση 2,5 μονάδων. **Πηγές:** Διαλέξεις 4 και 5, χειρόγραφες σημειώσεις.
